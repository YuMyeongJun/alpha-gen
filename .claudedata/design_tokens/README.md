# design_tokens/ — 사내 디자인 시스템 코어

이 폴더는 대시보드 고도화 대장정의 **디자인 토큰 진실 원천(정규화 사본)** 입니다.

## 원칙
- **런타임 진실:** `frontend/src/styles.scss` 의 `:root`. 실제 렌더링은 이 파일이 결정합니다.
- **이 폴더의 역할:** 토큰을 감사·핸드오프하기 위한 기계 판독 사본([tokens.json](tokens.json)). 세션이 바뀌어도 팔레트가 흔들리지 않게 박제.
- **동기화 방향:** 토큰을 바꿀 땐 `styles.scss` → `tokens.json` 순서로 반영하고, PR 설명에 diff를 남깁니다. (역방향 자동생성 스크립트는 아직 없음 — 필요 시 Phase 0에서 추가)
- **Figma MCP:** 현재 미연동. 연동되면 이 폴더가 Figma export의 착지점이 됩니다. 그전까진 `styles.scss` 추출값이 코어입니다.

## 현재 상태 (2026-08-12 감사)
- Light 테마 **전용**. dark/`data-theme`/`prefers-color-scheme` 분기 없음.
- `tokens.json`의 `dark_proposed` 값은 **Phase 0 초안** — 온-스크린 대비/명도 검증 후 확정하며, 확정 전엔 `styles.scss`에 반영하지 않습니다.
- semantic 색의 `50/100` 틴트는 다크에서 불투명 색상 대신 **낮은 알파 오버레이**로 치환 권장(밝은 블록이 다크 배경에서 튀는 것 방지).
