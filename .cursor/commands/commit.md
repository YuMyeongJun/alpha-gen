# alpha-gen Commit Generator

현재 변경 사항을 분석하여 alpha-gen 프로젝트의 커밋 메시지 규칙에 따라 작성해줘.

## 📝 규칙 가이드

- 형식: `[아이콘][타입]#티켓번호: 수정 내용`
- 언어: 한국어
- 티켓 번호: 현재 작업과 관련된 티켓 번호가 있다면 사용하고, 모른다면 ``으로 표시해줘.

## 🎨 아이콘 및 타입 매핑

- [✨][Feat]: 새로운 기능
- [🐛][Fix]: 버그 수정
- [📝][Docs]: 문서 수정
- [♻️][Refactor]: 코드 리팩토링
- [🔧][Chore]: 빌드/설정 파일 수정
- [🔨][Build]: 빌드 도구 수정
- [🚀][Deploy]: 배포/CI/CD 관련
- [⏪️][Revert]: 커밋 되돌리기

## 🤖 출력 양식

변경 사항을 요약한 후, 위 규칙을 적용한 커밋 메시지 '한 줄'을 바로 복사할 수 있게 제공해줘.
